# 规则规格

实体牌 ID 0…51 = 花色×13 + 点数−1，花色顺序黑桃、红桃、梅花、方块；A=1，2=2，…K=13。52、53 是小王、大王。黑桃 3 实体 ID 为 2。组合中 `cardIds` 始终保存原始 ID，`wildRanks` 保存癞子的逻辑点数。

54 张、四人各 13 张、弃两张；服务端洗牌。首局首手含真实黑桃 3；后续上一局赢家先出，首手禁止单 2、单王、对 22（含癞子代替）。限制只应用于整局第一次成功出牌，不影响后续自由领出，也不禁止含 2 的长牌型。

支持单、对、三不带、三带两张不同点数散牌、三带对、至少五张顺子、至少两组连对、至少两组连续三张的飞机（不带/2n 张不同散牌/n 个不同对子）、炸弹。附件不使用主体点数；无四带牌型。普通压制保持牌型、长度和组数一致。

连续性和普通点数比较分开。已确认 A2345 < 23456 < 34567、AA22 < 2233 < 3344、AAA222 < 222333。完整边界和演示策略见 [未决项](open-questions.md)。

枚举器先生成点数数量模板并做手牌长度/缺张/王数量剪枝，再按实体牌分配，输出所有替代方式和稳定去重结果。服务端当前合法组合是界面选牌、高亮、提示及最终出牌校验的共同来源。

每次成功出牌更新桌面、最后出牌者，连续无法压制计数归零。依次检查后续玩家；无合法压制则服务端自动跳过。每个玩家可以在同轮出牌任意多次；只有最后出牌者以外三人连续无法压制才结束该轮，由最后出牌者重新领出。有人手牌归零立即结算。

有普通或炸弹合法响应时必须出牌，但可以自由选择任何一个合法响应，不强制炸弹优先。协议没有主动过牌命令。

计分配置在 `ScoreRuleConfig`：1 张=档1，2…5=档2，6…9=档3，10…12=档4，13=档5；两套档值 [0,1,2,4,6] 和 [0,3,5,10,15]。赢家收取三家损失，总分零和。炸弹另计，2 炸弹档4、其他档3，每家支付；先即时入账，被更大炸弹压过时追加冲正记录，再入账新炸弹，每轮只保留最终炸弹得分。
