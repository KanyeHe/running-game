# 2026-10-20 前端阶段调整

用户将第一阶段前端目标从 Cocos/微信小游戏调整为 HTML5：先用浏览器验证并稳定玩法、联机和恢复，再迁移小游戏。本调整优先于原 requirements.md 中本阶段必须采用 Cocos/微信构建的要求；原文保留作为地方规则和长期目标来源。

后端继续使用 Java 25 / Spring WebSocket，房间、规则和积分需求不变。新增 `web` 浏览器客户端及同源静态资源，保留 `client` Cocos 源码。使用共享 TypeScript 传输与选牌模块，服务端候选和校验仍为唯一权威。

当前阶段验收应优先执行 H5 构建及四浏览器/四 frame 真服务联机，验证整局、重复请求、自动跳过、跨圈压制、计分、刷新和断网恢复。Cocos 引擎编译、微信域名、AppID 和微信真机发布暂缓，不再阻塞 H5 玩法验证。
